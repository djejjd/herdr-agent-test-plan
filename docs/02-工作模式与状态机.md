# 工作模式与状态机
状态: active  
创建: 2026-11-25  
最后更新: 2026-11-25  
关联: ../README.md

| 模式 | 可以做什么 | 转交条件 |
|---|---|---|
| INTAKE | 复述用户要观察到的行为 | 双方能用同一例子说明成功 |
| PLAN | 比较可行方案，列出文件范围和验收例子 | 产品取舍已确认 |
| IMPLEMENT | 在范围内选实现，先补行为测试 | 最小链路可演示 |
| VERIFY | 独立探索失败路径，保存可复现输入 | 风险有实测结果或明确缺口 |
| REVIEW | 对照用户裁决、diff 和验证证据 | 给出通过、返修或待用户 |
| REPAIR | 针对确认的问题做最小修复 | 回到 VERIFY 验证再送审 |
| REPORT | 汇总验收行为与遗留项 | 交回任务所有权并结束等待 |

阶段变化时更新任务卡。若修复需要改变协议、用户可见行为或模块边界，回到 PLAN。失败和取消同样记录原因，释放本任务持有的锁与监听器。
