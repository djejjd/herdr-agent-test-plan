# 多Agent分工与交接
状态: active  
创建: 2026-11-25  
最后更新: 2026-11-25  
关联: ../README.md

主管维护任务状态。实现者拥有明确文件范围。测试者可以增加测试；独立审查者取得原始需求、有效裁决、待审版本和 diff。小任务可以让独立审查者兼任测试者。

通过现有 MCP 或 hooks 传递 `started`、`blocked`、`needs_decision`、`completed`、`failed`。每条事件带任务 ID、来源会话、递增序号、原因、证据和下一步。重复序号只处理一次，旧序号不能覆盖新状态。失联记录为状态未知，向原会话核实。心跳只用于发现失联。

例如 T-7 的第 4 条事件报告测试通过，第 3 条阻塞消息随后到达。主管保留第 4 条状态，并核对交付所测提交。`completed` 触发待审；独立复核后才记已验收。
